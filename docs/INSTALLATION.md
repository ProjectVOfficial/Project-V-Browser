# Project V // Browser Installation

Public installation instructions will accompany the first validated GitHub release.

## Windows

When release assets are available, use only packages published through the official Project V GitHub repository.

Expected release formats may include:

- Windows installer
- portable Windows build

Exact formats will be documented after the current build is inspected and validated.

## Before installing

1. Verify that the download came from the official Project V repository.
2. Compare the file's SHA-256 value with the release checksum manifest when provided.
3. Read the release notes for version-specific requirements.
