# Project V // Browser Features

Project V // Browser is designed as a privacy-focused desktop browser within the Project V ecosystem.

Current project areas include:

- privacy-oriented browsing controls
- per-tab privacy and routing controls
- local security and download inspection
- hardened browsing workflows
- optional privacy-routing support
- Project V visual identity and desktop integration

This page will be updated from the validated application build before the first public release so that documented features match shipped behavior.
