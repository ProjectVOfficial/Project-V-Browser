# Public Release Checklist

Before marking a Project V // Browser build as stable:

- [ ] Confirm application version across package/build metadata.
- [ ] Run type checking and production build validation.
- [ ] Test installed build.
- [ ] Test portable build if provided.
- [ ] Confirm privacy-routing behavior.
- [ ] Test download/security workflow.
- [ ] Confirm application icon and Windows metadata.
- [ ] Remove credentials, local profiles, browsing data, caches, and private configuration.
- [ ] Review third-party licenses and redistribution obligations.
- [ ] Generate SHA-256 checksums.
- [ ] Prepare release notes.
- [ ] Upload only validated release artifacts.
- [ ] Confirm GitHub release tag matches application version.
