# Security Policy

## Supported releases

Only versions explicitly identified as supported on the GitHub Releases page should be treated as current Project V // Browser releases.

## Reporting a vulnerability

Please do not publish exploit details, credentials, private browsing data, or other sensitive information in a public issue.

When reporting a potential security problem, include:

- the Browser version
- Windows version
- steps required to reproduce the issue
- whether the issue affects browsing, downloads, privacy routing, local data, or update behavior
- logs or screenshots with sensitive information removed

Public issues may be used for non-sensitive bugs. Sensitive security reports should use GitHub's private vulnerability-reporting channel when enabled.

## Scope

Project V // Browser security documentation applies to Project V-authored Browser components and release packaging. Third-party engines, libraries, services, and external websites may have their own security policies and update cycles.
