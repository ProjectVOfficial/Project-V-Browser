# Project V // Browser

**Project V // Browser** is a privacy-focused Windows web browser developed as part of the Project V ecosystem.

The project is designed around local control, privacy-oriented browsing, per-tab security controls, and optional privacy-routing features while keeping the desktop experience straightforward and usable.

## Status

Project V // Browser is under active development. Public release packages and version-specific notes will be published through GitHub Releases after release validation is complete.

## Project goals

- Privacy-first browsing controls
- Per-tab privacy and routing options
- Hardened desktop browsing workflow
- Local security tooling and download inspection
- Clear user control over privacy features
- Portable and installed Windows release options where supported
