# Privacy

Project V // Browser is being developed around local control and privacy-conscious defaults.

Release-specific documentation will identify which features operate locally, which features may connect to external services, and which optional privacy-routing or security services are enabled by the user.

## Principles

- Browsing and security controls should be understandable to the user.
- Optional privacy features should remain user-controlled.
- Local data should not be silently uploaded by Project V.
- Project V should not require an advertising profile to use the Browser.
- Features that contact third-party services should be documented.

## Third-party services

Websites, search providers, update endpoints, privacy networks, DNS providers, and other services accessed through the Browser may independently receive network information. Their behavior is governed by their own policies.

This document will be expanded as the current public release is finalized.
